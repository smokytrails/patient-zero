## 1. What is the SIR model?
- mathematical model that describes how an infectious disease spreads through a population over time
- SIR:
    - susceptible
    - infected
    - recovered
- presumptions:
    - closed population
    - recovery -> immune
    - uniform mixing of population (think stars hallow)
    - no incubation period

## 2. Population
- hypothetical starting values:
    - overall: 1000
    - susceptible (S): 990
    - infected (I): 10
    - recovered (R): 0
- base understanding: N = S + I + R

## 3. Parameters that control the epidemic
- transmission rate ($\beta$)
- recovery rate ($\gamma$)
- hypothetical values:
    - $\beta$ = 0.3 per day
    - $\gamma$ = 0.1 per day
- with these values, the average infectious period will be 

    $1 / \gamma = 1 / 0.1 = 10 \ days$

## 4. Differential Equations:
- Susceptible: 
    - $dS/dt = -\beta(SI/N)$
    - susceptible individuals decrease because as more and more people get infected and pass on to recovery, they don't return to the susceptible stage
    - with the values in our hypothetical scenario, we get:
        
        $dS/dt = -0.3 \cdot (990 \cdot 10) / 1000$
        
        $= -2.97 \ people/day$

- Infected: 
    - $dI/dt = \beta(SI/N) - \gamma(I)$
    - increased infections (the first term) shows more people moving from the susceptible bucket to the infected one
    - we see a decrease at the rate of recovery as well
    - with the values in our hypothetical scenario, we get:
        
        $dI/dt = 2.97 - (0.1 \cdot 10)$
        
        $= 1.97 \ people/day$

- Recovered:
    - $dR/dt = \gamma(I)$
    - this rate only increases, because every recovered person becomes immune
    - with the values i out hypothetical scenario, we get:

        $dR/dt = 0.1 \cdot 10$

        $= 1 \ person/day$

## 5. What is the Basic Reproduction Number ($R_0$)
- formula: $R_0 = \beta / \gamma$
- represents the expected number of secondary infections generated by one infectious individual in a fully susceptible population
- for our hypothetical disease:

    $R_0 = 0.3 / 0.1 = 3$
- conditions:
    - if $R_0 < 1$, transmission is insufficient to sustain epidemic growth
    - if $R_0 = 1$, epidemic growth threshold
    - if $R_0 > 1$, infection grows as long as susceptible individuals are available
- note: even when $R_0 > 1$, infections don't increase forever, because susceptible people become fewer and fewer as infected and recovered people increase
- effective reproduction number for our simple model:
    - $R_eff(t) = R_0 (S(t) / N)$
    - when this number falls below 1, the infected population starts declining
